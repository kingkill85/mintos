# rgarch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A small libretro frontend `rgarch` with a MinUI-style in-game menu that replaces RetroArch for all software-rendered systems on the RG353V (phase 1); phase 2 adds the GL cores.

**Architecture:** One process per game, started by `launch.sh` instead of RetroArch. C + SDL2 (KMSDRM video through SDL_Renderer/GLES2, GameController, audio) + SDL2_image (PNG overlays and previews). Pure logic (config, paths, viewport maths, audio rate control, input mapping, menu state) lives in SDL-free files with host unit tests; everything touching SDL/the core is tested on the PC with SDL's dummy drivers and a test core, then on the device with `fbgrab`/`rg353-press`.

**Tech Stack:** C11, SDL2 2.32, SDL2_ttf, SDL2_image (Debian trixie on the device), libretro API (`libretro.h` from the libretro-common project, MIT), zig cc cross-compile (as `build.sh`), host tests with gcc via nix-shell.

**Spec:** `docs/superpowers/specs/2026-11-08-rgarch-design.md`

## Global Constraints

- Paths: saves `/storage/saves/<system>/<Spielname>.srm` (+ `.rtc`), states `/storage/states/<system>/<Spielname>.st<n>` + `.st<n>.png` (n = 0..8), auto state `/storage/states/<system>/<Spielname>.auto`, log `/var/log/rgarch.log`, config `/storage/.config/rgarch/systems.cfg`.
- `<system>` = folder name under `/storage/roms`; `<Spielname>` = ROM file name without its last extension.
- Core options: read/write `/storage/.config/retroarch/config/<library_name>/<library_name>.opt` (RetroArch format `key = "value"`), cores from `/storage/.config/retroarch/cores/<core>_libretro.so`, system dir `/storage/roms/bios`.
- Menu items (German, this order): Weiter, Speichern, Laden, Beenden. Without savestate support only Weiter, Beenden. 9 slots, left/right switches, A executes, B / F closes.
- Look: BPreplay Bold (`/storage/.config/rglauncher/fonts/BPreplayBold-unhinted.otf`), sizes 32/24/28, PAD 20, PILL 60, HINT 60, BTN 44, colours as in `launcher/rglauncher.c` (WHITE, BLACK, DARK 0x262626, LIGHT 0xcccccc, MID 0x808080).
- F = SDL_CONTROLLER_BUTTON_GUIDE of "RG353V Gamepad" opens the menu; no other hotkeys.
- Audio out 48000 Hz stereo, queue target 64 ms.
- Exit to the list within 2 s; never open-and-close the display before handing it on (panel goes black).
- SRAM autosave every 60 s when changed; state files written to `<file>.tmp` then renamed.

## Review Focus

- Core changes geometry/pixel format mid-game (Nestopia NTSC toggle, PS1 resolution switches) → picture keeps correct scale, no crash. Test in Task 6.
- ROM names with spaces, quotes, umlauts, brackets (`Legend of Zelda, The - Link's Awakening DX (USA, Europe) (Rev 2).gbc`) → saves/states land under the right name. Test in Task 3.
- Power key while the menu is open or while a state is being written → auto state is a complete file (tmp+rename), resume works. Test in Task 9.
- Cores not at 60 Hz (PAL 50 Hz, arcade 57.5 Hz, GB 59.73 Hz) → no crackle, no drift. Test in Task 7.
- Core fails to load (missing BIOS, bad ROM) → German error page, B returns to the list, no hang. Test in Task 11.

## File Structure

```
common/ui.c, common/ui.h        MinUI drawing shared by launcher and rgarch (fonts, pill, text, hints, battery)
frontend/libretro.h             upstream libretro API header (vendored, MIT)
frontend/config.c/.h            systems.cfg parser -> SystemCfg
frontend/paths.c/.h             save/state/auto/preview path builders
frontend/viewport.c/.h          scale mode + core geometry -> dest rect (pure maths)
frontend/ratecontrol.c/.h       dynamic audio resample ratio (pure)
frontend/inputmap.c/.h          SDL controller button -> RETRO_DEVICE_ID_JOYPAD_* table (pure)
frontend/menu.c/.h              menu state machine (pure) + menu_draw() (SDL)
frontend/core.c/.h              dlopen + environment callbacks + options (.opt)
frontend/video.c/.h             SDL window/renderer, frame upload, sharp filter, overlay
frontend/audio.c/.h             SDL audio + SDL_AudioStream + pacing
frontend/state.c/.h             SRAM/RTC load/save, savestates + previews, auto state
frontend/main.c                 arg parsing, main loop, SIGTERM, error page
frontend/test/*.c               host unit tests (one file per pure module) + testcore.c
frontend/test/run.sh            builds and runs host tests (nix-shell gcc, SDL dummy)
frontend/test/device-smoke.sh   on-device acceptance (fbgrab, rg353-press)
os/files/storage/.config/rgarch/systems.cfg
os/files/usr/local/sbin/rg353-migrate-saves
```

`build.sh` builds `build/rglauncher` and `build/rgarch`; `deploy.sh` copies both.

**Interfaces:**
- Produces:
  ```c
  /* queued and target in bytes; returns resample ratio multiplier, clamped to [0.995, 1.005] */
  double rate_adjust(size_t queued, size_t target);
  int  audio_open(double core_rate);          /* 48000 Hz S16 stereo out */
  ```
